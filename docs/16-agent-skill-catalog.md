Each skill file must include purpose, when to use, required reading, steps, files usually touched,
tests/checks to run, forbidden patterns, and definition of done.

Skill files reinforce core portability, explicit boundaries, risk-based tests, no framework leakage,
no heavy abstractions, quality gates, and type safety with compile-time feedback.
